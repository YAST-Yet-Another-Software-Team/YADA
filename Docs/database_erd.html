Auth Core

The login/session layer is backed by users, sessions, accounts, and verifications.

Workspace Profiles

Businesses and couriers both branch from the same user record, but each workspace has its own profile table and behavior.

Trip History

Delivery requests drive the workflow, while trip events, ratings, and declines capture everything that happens around a job.
